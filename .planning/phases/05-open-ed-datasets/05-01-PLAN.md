until we have a verifiable license trail. This audit is the gate.

Output:

    Write a Python script that, for each candidate dataset listed in CANDIDATES
    (hard-coded list inside the script), calls `huggingface_hub.dataset_info()`
    to fetch its license tag, row count (sum across splits if multi-config),
    and citation. CANDIDATES must include at minimum:

    Math: nvidia/OpenMathInstruct-2, hendrycks/competition_math, openai/gsm8k,
          deepmind/aqua_rat, math_qa, microsoft/orca-math-word-problems-200k
    Reasoning/verbal: cais/mmlu, allenai/ai2_arc, google/boolq, lukaemon/bbh,
                     EleutherAI/lambada_openai
    Long-form CC: openstax (via openstax-cc), nampdn-ai/tiny-textbooks,
                  nvidia/HelpSteer

    For each: print a markdown table row with id, license, ~row count, content
    type (Q&A | reasoning | textbook), and "commercial: yes/no" based on
    license (CC-BY-* yes, CC-BY-NC* no, MIT/Apache yes, unknown -> flag).

    Output goes to stdout in markdown so we can pipe it into LICENSES.md.
    Use try/except per dataset — if HF rate-limits or the dataset moved, log
    a TODO row rather than crashing the whole script.
