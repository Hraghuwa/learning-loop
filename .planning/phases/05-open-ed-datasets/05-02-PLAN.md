</objective>

<task type="auto">
  <name>Task 1: Implement scripts/ingest_math.py</name>
  <files>scripts/ingest_math.py</files>
  <action>
    Build an ingestion script that:

    1. Reads LICENSES.md (or a hard-coded subset cross-checked against it)
       to know which math datasets to pull. Use only INCLUDE=yes rows.
    2. For each dataset, streams the train split via `datasets.load_dataset`
       with `streaming=True` to avoid loading 14M rows into RAM.
    3. Normalizes every row into this schema:
         {
           "id":          "<dataset_slug>_<idx>",
           "problem":     "<question text>",
           "answer":      "<final answer string>",
           "solution":    "<full worked solution if present, else null>",
           "subject":     "math",
           "subDomain":   "<heuristic: algebra|arithmetic|geometry|word-problem|other>",
           "source":      "<hf dataset id>",
           "license":     "<license string from LICENSES.md>",
           "url":         "<huggingface dataset url>"
         }
    4. Per-dataset extractor functions handle field mapping:
         - OpenMathInstruct-2: problem=`question`, answer=`expected_answer`,
           solution=`generated_solution`
         - competition_math (MATH): problem=`problem`, answer=`solution`
           (final boxed), solution=`solution`
         - gsm8k: problem=`question`, answer=last "#### N" group,
           solution=`answer`
         - aqua_rat: problem=`question + options`, answer=`correct`,
           solution=`rationale`
         - math_qa: problem=`Problem`, answer=`correct`, solution=`Rationale`
         - orca-math-word-problems-200k: problem=`question`,
           answer=`answer`, solution=null
    5. Writes JSONL incrementally (one row per line) to
       datasets/math-corpus.jsonl with a tqdm progress bar.
    6. Skips rows where `problem` is shorter than 20 chars or `answer`
       is empty/null.
    7. At the end, writes datasets/math-corpus.stats.json:
       { "<source>": {"rows": N, "license": "..."}, ... , "total": N }

    Provide a CLI flag `--limit-per-source` (default: 200000) so we can
    cap each source while testing, and `--sources` (comma list) to filter.

    Avoid: do NOT shuffle, do NOT split into train/test here (that's a
    later step). Do NOT load full datasets into memory.
  </action>
  <verify>
    source ~/autogluon-env/bin/activate
    # Smoke test with tiny cap
    python scripts/ingest_math.py --limit-per-source 50
    wc -l datasets/math-corpus.jsonl   # ≥ 200 (50 × ~4 sources)
    python -c "import json; r=json.loads(open('datasets/math-corpus.jsonl').readline()); assert set(r) >= {'id','problem','answer','source','license'}, r"
  </verify>
  <done>
    Script runs end-to-end on small cap, emits valid JSONL with all required
    fields, and writes a sane stats.json.
  </done>
</task>
