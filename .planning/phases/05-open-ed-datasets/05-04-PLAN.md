<objective>
Ingest CC-licensed long-form educational text (textbook chapters, lecture
transcripts) and chunk it into passage-level rows that can be retrieved by
the RAG layer in Phase 8.

This is *not* Q&A — it's the explanatory prose the tutor needs to cite when
walking a student through a concept. Without it, every answer is just
"the answer is X" with no pedagogy.

Output:
  - scripts/ingest_longform.py
  - datasets/longform-corpus.jsonl       (≥ 100K passages expected)
  - datasets/longform-corpus.stats.json
</objective>

  <name>Task 1: Implement scripts/ingest_longform.py</name>
  <files>scripts/ingest_longform.py</files>
  <action>
    Build an ingestion script for textbook / lecture-transcript content.
    Sources (only INCLUDE=yes from LICENSES.md):

      - nampdn-ai/tiny-textbooks         (synthetic but CC; carry as such)
      - openstax CC chapters             (if HF mirror unavailable, fetch
        the openstax CC-BY-4.0 export from openstax.org/details/books and
        parse the HTML/JSON; if that's out of scope for v1, document it in
        SUMMARY and skip — do not block on it)
      - nvidia/HelpSteer                 (instruction + response, license check)

    Row schema (different from Q&A schema — this is passage-level):
      {
        "id":          "<source>_<chapter|doc>_<chunk_idx>",
        "passage":     "<300-1200 token chunk>",
        "title":       "<chapter or doc title>",
        "subject":     "longform",
        "subDomain":   "<heuristic: arithmetic|algebra|geometry|verbal|...>",
        "source":      "<dataset id or url>",
        "license":     "<license>",
        "url":         "<source url>"
      }

    Chunking rule: split on paragraph boundaries, target 400 tokens per
    chunk with 50-token overlap. Use simple whitespace + sentence splitter
    (regex on `[.!?] `) — do NOT pull in NLTK/spaCy just for this.

    Skip chunks shorter than 100 chars or longer than 4000 chars.

    Carry license/url through. Same CLI flags as the other ingest scripts
    (`--limit-per-source`, `--sources`).

    Avoid: do NOT scrape any third-party non-CC site. If OpenStax HTML
    parsing turns out to be brittle, log it and move on — the math +
    reasoning corpora are the must-have; longform is the nice-to-have.
  </action>
  <verify>

    python scripts/ingest_longform.py --limit-per-source 30
    wc -l datasets/longform-corpus.jsonl
