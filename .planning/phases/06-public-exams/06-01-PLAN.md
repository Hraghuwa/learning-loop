<task type="auto">
  <name>Task 1: Build scripts/verify_exam_sources.py</name>
  <files>scripts/verify_exam_sources.py</files>
  <action>
    Create a Python script with a hard-coded SOURCES dict mapping each exam
    to a list of candidate official-PDF URLs. Use only these primary
    publishers (which release papers as public-domain government documents):

      JEE_MAIN  : nta.ac.in /  jeemain.nta.nic.in  (year-wise question paper PDFs)
      NEET      : neet.nta.nic.in                  (year-wise question paper PDFs)
      UPSC_CSE  : upsc.gov.in/examinations/previous-question-papers
      GATE      : gate.iitm.ac.in (or current host) — IIT-published papers
      NCERT_QB  : ncert.nic.in (chapter-end question banks, CC-BY-NC-SA → mark
                  INCLUDE=no but record for reference)

    DO NOT include:
      - CAT (IIMs do not officially release past papers — memory-based
        reconstructions are copyrighted by coaching institutes; SKIP entirely
        and document why in SOURCES.md)
      - Any third-party site mirroring official PDFs (use only the
        original publisher to avoid stale links and licensing ambiguity)

    For each URL the script must:
      1. Send a HEAD (fallback GET) with a 15s timeout and a normal browser
         User-Agent. Capture status code + Content-Type + Content-Length.
      2. Record license = "Government of India (public domain, Sec 52 IT Act)"
         for nta/upsc/iit URLs; CC-BY-NC-SA for NCERT.
      3. Output a markdown table row: exam | year | url | status |
         content-type | size_kb | license | INCLUDE? (yes if status=200 and
         content-type contains "pdf").

    Provide CLI flag `--exam` to filter (e.g. `--exam JEE_MAIN`).
    Output goes to stdout in markdown — same pattern as audit_datasets.py.

    Avoid: do NOT download the PDF body in this script. HEAD-only (with GET
    fallback only if HEAD returns 405/403). We are just verifying existence.
  </action>
  <verify>
    source ~/autogluon-env/bin/activate
    python scripts/verify_exam_sources.py --exam JEE_MAIN 2>&1 | head -20
    # Should produce a markdown table with status codes per URL.
  </verify>
  <done>
    Script runs without crashing on any exam category, produces a markdown
    table with one row per URL, and correctly flags 200/404/403 status codes.
  </done>
</task>

    2. Per-exam tables: one section per exam (JEE Main, NEET, UPSC CSE,

    3. Excluded section: explicit list of sources we are NOT pulling (CAT,
       NCERT, any third-party mirror) with one-line reason each.

    4. Aggregate stats at the bottom: total INCLUDE=yes URLs by exam,
       estimated total PDFs to download in 06-02.

    Rules:
      - Any URL with status != 200 → INCLUDE=no, mark with a TODO row.
      - Any URL whose content-type doesn't contain "pdf" → INCLUDE=no.
      - The "INCLUDE=yes" set is the gate for 06-02.
  </action>
